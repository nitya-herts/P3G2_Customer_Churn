# Development Log

Use one entry per actual work session. Do not fill earlier dates from memory unless supported by contemporaneous evidence (for example, notebook history, meeting notes, messages or saved files). If a task was completed earlier and committed later, record both dates separately.

| Actual work date | Contributor(s) | Work completed | Evidence (commit, file, screenshot, meeting note) | Follow-up |
|---|---|---|---|---|
| YYYY-MM-DD |  |  |  |  |

## Commit date versus work date
Git commit timestamps show when commits were created. They do not independently prove when the underlying work was performed. Record actual work dates and commit dates separately where they differ.
