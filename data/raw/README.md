# Raw Dataset

## 1. Overview
This directory stores the original source files used for the Customer Churn Analysis and Prediction project.

These files provide the input data required for data analysis and the ETL (Extract, Transform, Load) pipeline.

## 2. Source Dataset Files

The following source files are expected in this directory:

| File Name | Description |
|---|---|
| `PerfectPetClub.db` | Original database file |
| `PerfectPetClub_CRM_report.csv` | CRM report data |
| `PerfectPetClub_server_log.csv` | Server log data |
| `PerfectPetClub_survey.csv` | Customer survey data |

## 3. Data Availability

The above source files were not included in the notebook upload.

They should be placed in this directory when the authorised files become available.

## 4. Purpose of Raw Data

The raw data is used for:

- Data quality checking.
- Missing-value analysis.
- Duplicate detection.
- Data preprocessing.
- Feature analysis.
- Customer churn analysis.

## 5. Data Processing

The raw source files are intended to be used as input for the ETL pipeline.

The ETL process extracts, transforms and prepares the data for further analysis and machine learning.

## 6. Data Permissions

Before uploading any original source dataset to GitHub, check the project's data permissions.

Only authorised source files should be committed to the repository.
